# 🛰️ The Mission: Verification Over Claims

**HotDrop** is a **Proof-of-Work ecosystem for developers**.

| Platform    | What it Shows             |
| ----------- | ------------------------- |
| GitHub      | Source Code               |
| LinkedIn    | Achievements              |
| **HotDrop** | **Live Working Projects** |

HotDrop verifies whether your project is **actually deployed and running**.

If the deployment goes down, the platform immediately **flags the project status**.

No fake portfolios.
No dead links.
Only **real working products**.

---

# ✨ Key Features

## 🟢 Real-Time Heartbeat Monitoring

HotDrop continuously monitors the health of every project URL.

**System Behaviour**

• Live deployment → Green status
• Server crash → Marked inactive
• Broken URL → Instantly flagged

This keeps the platform filled with **real, working projects only**.

---

## 🖼️ Triple-Image Interactive Gallery

Each project can include **up to 3 high-quality images**.

Powered by **Framer Motion** for modern interface animation.

---

## 🛡️ Iron-Clad Security

HotDrop follows strong authentication practices.

**Security Model**

• JWT authentication
• HttpOnly cookies (no LocalStorage tokens)
• Bcrypt password hashing
• Email verification with Nodemailer

Even the platform developers **cannot view user passwords**.

---

## 🤖 AI Co-Pilot

HotDrop includes an integrated **AI assistant** that helps developers:

• Understand the HotDrop platform
• Generate new project ideas
• Learn trending technology stacks
• Get guidance when deployments fail

The AI assistant helps users **keep building continuously**.

# ⚙️ System Architecture

User
↓
React Frontend
↓
Express API
↓
Node.js Server
↓
MongoDB Atlas

**Workflow**

1. User uploads project
2. Backend validates the live URL
3. Database stores project data
4. Monitoring service tracks link health
5. Frontend displays live status
